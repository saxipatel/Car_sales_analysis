# Dataset Information

This project analyzes car sales transactions using Microsoft Power BI.

The dataset contains information about vehicle sales, including:

- Car ID and transaction date
- Customer and dealer information
- Vehicle company and model
- Body style, color, engine, and transmission
- Vehicle selling price
- Dealer region

The Power BI report is available in the repository as `FinalProject.pbix`.

**Data Source:** The original dataset file and its source URL are not currently available.

The dashboard includes sales performance analysis, vehicle trends, and dealer-level insights.
